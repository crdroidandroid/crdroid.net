# crDroid 12.9 Release

We’re releasing crDroid 12.9. This update includes the latest security patches, new customization options, and a wide range of fixes and improvements.

## Highlights

* Initial crDroid 12.9
* April 2026 security patches
* Implemented new Play Integrity spoof options (crDroid Settings → Misc)
* Implemented built-in TrickyStore (crDroid Settings → Misc)
* Added status bar dynamic bar
* New clock styles and clock face feature
* Added classic QS panel style
* Added theme packs for Wi-Fi, signal, and system icons

## New features and improvements

### Customization

* Added more classic icon shapes
* Added theme packs for Wi-Fi icons, signal icons, and system icons
* Added clock face feature
* Added classic QS panel style for tiles

### Launcher3

* Added revamped Pixel-style dock search bar
* Introduced app drawer styles
* Added app drawer sort options
* Turned app drawer sort into a user preference
* Added app drawer search bar location
* Allowed custom background colors for the app drawer
* Improved dark text on app drawer toggle
* Fixed double tap on home screen to turn off screen
* Fixed gesture abort freeze when nav hint is disabled
* Fixed alpha calculation for all apps search bar
* Fixed crash in vertical app drawer styles
* Various small fixes

### SystemUI

* Added status bar dynamic bar
* Fixed NPE in ongoing chip icon rasterization
* Improved clock layouts and fonts
* Allowed Omnijaw weather to show on AOD
* Kept Wi-Fi QS tile subtitle Wi-Fi-specific

### Performance and system

* LMOFreeform uses max supported refresh rate for freeform windows
* LMOFreeform prefers highest refresh rate display mode
* Added hooks for custom ROM hiding in bionic
* Fixed possible crashes caused by bitmap drawing
* Updated Chromium WebView to 146.0.7680.153

### Input and gaming

* Various keyboard changes
* Various GameSpace changes

## Changes and cleanup

* Removed compact chip toggle for dynamic bar
* Dropped ongoing action chip implementation
* Settings: hide ambient from search
* Updated translations
* Some other smaller changes

## Notes

This release focuses on improving stability, performance, and customization while keeping the experience clean and consistent.

## Support and feedback

If you encounter issues or have feedback, report them through the usual channels.

Enjoy crDroid 12.9!
