## crDroid 11.4 is now released!
----------------

We’re happy to roll out **crDroid 11.4**, continuing our journey with the latest **Android 15 QPR2 (android-15.0.0_r26)** security updates and a fresh batch of improvements, bug fixes, and customization options.

This release focuses on **enhancing stability, fine-tuning user experience**, and expanding our unique features while keeping things smooth and modern.

### What’s new in crDroid 11.4 ###
**Security & Core Updates**
- Updated Android security patches to **April 2025 (android-15.0.0_r26)**.
- Improved system translations across more locales.

**System Enhancements & Fixes**
- **Fixed an issue** where apps could become unresponsive when **navigation hints were hidden**.
- **Resolved A2DP volume issues** affecting devices with **multiple audio outputs**.
- **Disabled Safe Media Volume Management** for better user control.
- **Improved SystemUI stability**, including:
  - Fix for **VolumeDialog touchable region** when using per-app volume.
  - **Toast message added** when restarting SystemUI.
  - **Support for double line clock** restored on the lockscreen.
  - **Fixed dark mode UI inconsistencies**.
  - **Brightness fluctuation fix** imported from Android 16 Beta 3.1.

**Customization & UI Improvements**
- **New power menu styles** available under  
  **crDroid settings > User interface > Power menu styles**.
- **New notification styles** added to  
  **crDroid settings > User interface > Notification styles**.
- **3-button navigation layout settings** revamped for flexibility.
- **Slider haptics improved** for a better tactile experience.
- **Screen recording** now defaults to capturing the entire screen.

**Launcher3 Updates**
- **QuickSpace**:
  - Improved media event handling.
  - Now uses **raw weather conditions** for English language.
  - **Translated weather strings** now used where available.
- **Launcher animations optimized** for smoother transitions.
- Fixed **app freeze issues** when **gesture hints are disabled**.

**Smartspace & SystemUI Updates**
- **Reverse-engineered Smartspace implementation** now integrated.
- Layout and padding fixes for a more polished appearance:
  - Smartspace layout fixes.
  - Large clock top margin adjusted for Pixel framework.
  - Restored original smartspace start paddings.
  - Date text no longer hidden on lockscreen when media is playing.
  - **Toast UI**: fixed theme inconsistencies.
