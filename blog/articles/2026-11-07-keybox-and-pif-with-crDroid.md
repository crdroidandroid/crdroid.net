### Play integrity & Keybox configuration 

For those who need it, the following configuration can help improve Play Integrity verdicts and compatibility with applications that enforce device integrity checks, such as banking apps, Google Wallet and other security-sensitive services.

**Configuration**

If you don't already have a Keybox, you can obtain one from either of the following sources:

1. [https://keybox.kowx712.cc](https://keybox.kowx712.cc)
2. [https://t.me/IntegrityBox](https://t.me/IntegrityBox)

Those are only for reference only and you can obtain this from different other sources online.

Follow these steps:

1. Download the latest available Keybox XML file.
2. Import the XML under **crDroid Settings > Misc > TrickyStore**.
3. Ensure you have a valid PIF (Play Integrity Fix) configuration loaded under **crDroid Settings > Misc > Play Integrity Fix**.

**Disclaimer**

While this setup may help achieve the required Play Integrity verdicts and improve compatibility with certain applications, results are not guaranteed. Some applications implement additional security checks and may still detect an unlocked bootloader, root access or other device modifications.

Use these configurations at your own discretion. Results may vary depending on your device, configuration and the applications you use.
