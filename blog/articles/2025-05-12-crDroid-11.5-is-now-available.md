## crDroid 11.5 is now released!
----------------

We’re excited to announce the release of **crDroid 11.5**, continuing our focus on **refinement, reliability**, and **user control**. This version includes the latest **Android 15 QPR2 (android-15.0.0_r32)** security patches, along with several improvements and thoughtful additions across the system.

### What’s new in crDroid 11.5 ###
**Security & Core Updates**
- Updated Android security patches to **May 2025 (android-15.0.0_r32)**.
- Updated **Chromium WebView to 135.0.7049.100** for improved web compatibility and performance.
- Translations updated for a more localized experience.

**System Enhancements & Fixes**
- **Initial crDroid 11.5 release!**
- **Settings**:
  - Added support for **disabling non-system apps**.
  - Fixed **loading iconpack-based Wellbeing icon**.
  - Updated **build number display** behavior.
- **PowerShare**: Fixed QS tile state toggle issues.
- **PIN scrambling**: Fixed layout issues when unlocking.
- **SystemUI**:
  - Fixed **restart prompt** after settings changes.
  - Adjusted **keyguard user avatar margins**.
- **ThemePicker**: Resolved UI issues.
- **DeskClock**: Fixed **“Select All”** in label dialog.
- Added **Comss DNS provider**.
- Added support for **manually installed Google sound picker**.

**Launcher3 Updates**
- **Navigation button dimensions** now use _match_parent_ for consistency.
- **Home button double-tap handling** reworked for better responsiveness.
- **App info from recents** no longer uses a bottom sheet.
- Fixed:
  - Allowing **workspace edit** to be disabled.
  - Proper implementation of **taskbar toggle**.
- **Launcher animations** and transitions improved.

**Gaming Experience**
- **GameSpace**:
  - **DanmakuService** cleaned up and optimized.
- **GameBarService**:
  - Improved **panel animations** for smoother UI.

### Closing thoughts ###
----------------

**crDroid 11.5** brings further polish to your device, focusing on small but impactful tweaks that enhance performance, control, and stability. We’re proud of this release and can’t wait for you to explore it.

Grab the latest build from our [downloads page](https://crdroid.net/downloads) and enjoy the experience.

Stay tuned for more updates, and enjoy crDroid 11.5!
