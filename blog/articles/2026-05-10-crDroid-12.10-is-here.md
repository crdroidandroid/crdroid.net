# crDroid 12.10 – May 2026 security patch

crDroid **12.10** is now rolling out, bringing the May 2026 Android security patches together with a fresh set of features, customization improvements, UI refinements, and additional stability work across the system.

This update continues refining the Android 16 experience with improvements to SystemUI, Dynamic Bar behavior, Launcher3, audio feedback customization, freeform window support, and more under-the-hood enhancements for everyday usability.

## What’s new

### Security & Core

- Merged May 2026 Android security patches
- Updated Chromium WebView to *147.0.7727.101*
- Added Sandbox app
- Added ThemeStore support
- Added overlays for:
  - Battery styles
  - Charging animations
  - Back gesture styles
- Improved compatibility for custom ROM hiding implementations
- *pif*: Skip *SDK_INT* spoofing for vending process
- TrickyStore now restores target mode from disk on fragment resume

### UI, Media & System Experience

- Added animation styles for QS tile toggles
- Added additional Quick Settings tile animation styles
- Added subtle haptics on bass spikes
- Added configurable bass haptics playback for Pulse
- Added edge light preview support
- Dynamic Bar fixes and refinements
- Improved Dynamic Bar guide step layouts
- Fixed expanded content top padding in Dynamic Bar
- Added separate Dynamic Bar card for active calls
- Added SystemUI QuickLook client
- Various Smartspace improvements

### Launcher & Multitasking

Launcher3 continues receiving optimizations and polish:

- Various Launcher3 improvements and refinements
- Improved Freeform windows support
- Better multitasking behavior and stability improvements

### Customization & Extra Features

- Added Smart Pixels support  
  *(best left disabled unless you specifically know how to configure and use it effectively)*

- ThemeStore integration for easier UI customization
- Additional UI consistency and styling improvements

### Stability & Compatibility

- Fixed conflicts between built-in TrickyStore/PIF and modded versions
- Various fixes for Dynamic Bar behavior
- Additional system stability improvements
- Various smaller fixes and cleanup throughout the system

## Notes

This release continues polishing the Android 16 experience while also introducing several new customization options and backend improvements.

The new ThemeStore implementation allows easier customization of visual elements without requiring deeper manual modifications, while Dynamic Bar and Launcher3 continue receiving iterative refinements.

Smart Pixels support has also been added for users interested in experimenting with additional battery-saving techniques, though for most users it is generally recommended to leave it disabled.

As always, device-specific changes may vary depending on the maintainer.
