# crDroid 12.11 – June 2026 security patch

crDroid **12.11** is now rolling out, bringing the June 2026 Android security patches together with a large collection of usability improvements, lockscreen customization enhancements, Launcher3 refinements, GameSpace updates and continued stability work across the entire system.

This release focuses heavily on polishing the Android 16 experience while introducing new clock customization options, additional personalization features, improved multitasking behavior and numerous fixes throughout SystemUI, Settings, Launcher3, Sandbox and other core components.

## What's new

### Security & Core

* Merged June 2026 Android security patches
* Updated Chromium WebView to *148.0.7778.120*
* Improved user-specific spoofing settings handling
* Added app picker screen for TrickyStore target applications
* Various TrickyStore improvements and refinements

### Lockscreen & Personalization

Customization continues to be one of crDroid's strongest areas:

* Added new iOS-inspired clock styles
* Added custom Always-On Display clock transitions
* Introduced a dedicated lockscreen clock picker interface
* Clock previews now display the current lockscreen wallpaper
* Fixed clock style preview issues
* Added custom carrier label customization
* Added location text customization options
* Added Settings icon background customization

### Launcher3 & Multitasking

Launcher3 receives another major round of improvements:

* Added custom recents view styles
* Recents style changes now apply instantly
* Added ability to lock applications in recents
* Improved recents dismiss animations
* Smoother custom recents transitions
* Fixed animation snapping when entering custom recents
* Fixed recents gesture cleanup behavior
* Fixed stack recents dismiss reflow issues
* Fixed card drag z-index ordering
* Fixed clock icon crash related to LayerDrawable handling
* Fixed CPU drain caused by stack trace logging
* Updated launcher preferences with Material Expressive icons
* Additional Launcher3 optimizations and under-the-hood improvements

### GameSpace & Gaming

Several improvements have been added for gamers:

* Added launch icons for games inside the GameSpace library
* Added option to disable Pulse bass haptics while gaming
* Disabled status bar brightness gestures when auto-brightness is active
* Various GameSpace refinements and usability improvements

### SystemUI & Settings

* Added Settings icon background customization
* Styled the Settings search bar to match the new Settings design
* Added icon tinting support in Volume Slider preferences
* Fixed notification settings resource issues
* Fixed notification app lock related issues
* Dynamic Bar UI fixes for lockscreen and keyguard scenarios
* Improved status bar brightness behavior in specific edge cases

### System Improvements

* Added partial screenshot action
* Fixed partial screenshot functionality
* Fixed "Open with" behavior for cloned applications
* OmniJaws improvements
* LMOFreeform improvements
* Sandbox authentication lifecycle fixes
* DeskClock landscape UI fixes
* Updated translations across the system
* Various stability improvements and bug fixes throughout the ROM

## Notes

crDroid 12.11 continues the ongoing effort of refining Android 16 while expanding customization possibilities for users who enjoy tailoring every aspect of their device.

The new lockscreen clock picker, custom clock transitions and additional clock styles provide significantly more flexibility for personalizing the lockscreen experience. Launcher3 also receives another substantial update, with smoother animations, new recents layouts, task locking support and multiple performance improvements.

GameSpace users will also appreciate the additional controls and quality-of-life improvements introduced in this release.

As always, device-specific changes may vary depending on the maintainer.
