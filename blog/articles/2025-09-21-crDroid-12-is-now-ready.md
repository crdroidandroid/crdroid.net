# crDroid 12.1 release notes  

We’re a bit late with this post, and for that **we are sorry for the delayed post**. That said, it doesn’t really matter much — crDroid maintainers were already busy **pushing the update even without the announcement**, making sure you had access to the latest improvements as fast as possible.  

Also worth noting: **QPR1 is not yet merged into AOSP**, so those features are not part of this release. They’ll be pushed in future updates once ready.  

---

## What’s New in crDroid 12.1

### System & Security
- **Initial crDroid 12.1 release**  
- **Merged Android September 2025 Security patches**  
- **Memory usage**: Test fix for the transparency option that was leaking and consuming too much RAM  

### Quick Settings
- Added option to control **rows and columns** in QS  
- Added toggle for **QS tile haptic feedback**  

### UI & Customization
- **CustomSeekBarPreference** improvements  
- **OmniJaws**: Switched to **material expressive design** for preferences  
- **DocumentsUI**: Proper background support in dark theme  

### Apps & Features
- **LMOFreeform**: Fixed wrong padding in AllAppActivity  
- **Aperture**: Updated with the latest changes  
- **Launcher**: Various fixes for stability and performance  

### Miscellaneous
- **Small fixes and changes** throughout the system to improve stability and polish  

---

## Closing Notes

This release brings a stable and improved crDroid 12.1 experience, with fresh security patches, new customization features, UI refinements, and bug fixes.  

QPR1 features are on the horizon, and we’ll roll them out in future updates once they’re merged upstream.  

As always, thanks for the continued support, and enjoy the update!
