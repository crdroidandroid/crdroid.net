# crDroid 12.12 is now released

We are happy to announce the release of **crDroid 12.12**, bringing the September 2026 security patches along with a number of smaller improvements and fixes.

This release is intentionally focused on keeping crDroid 12 stable and up to date while the team's attention increasingly shifts toward the next major version.

## What's new

- **Initial crDroid 12.12**
- **September 2026 Android security patches**
- **Various quality-of-life fixes and improvements**
- **Updated translations**

## About the August security patches

You may have noticed that crDroid 12.12 skipped the August security patch level.

The reason is fairly straightforward: Google did not bring anything substantially new to the table for that month beyond what was effectively a string change. Rather than spending development and release time on an update with little practical value, we decided to invest that time into the next version of crDroid.

In other words, we chose to prioritize **crDroid 13** and the work required to bring it to a proper beta release.

## crDroid 13

Work on **crDroid 13** is already underway as you saw in our previous blog post and the project has now reached a **semi-public release stage**, with some users already testing early alpha builds and providing feedback.

Development of the **crDroid 13 BETA** is also progressing at a more accelerated pace now. We are currently planning to push the source code **later this month** and for now, everything remains **on schedule**.

There is still work to do before crDroid 13 is ready for a broader beta release, so testing and stabilization remain the priority. The current pace however is encouraging and we are continuing to move toward the planned milestone.

## Final words

For crDroid 12 users, 12.12 keeps the current release maintained with the latest September security patches, translations and a collection of smaller fixes.

At the same time, the team's focus is increasingly moving toward crDroid 13. We appreciate everyone testing the early builds and helping us identify issues before the beta reaches a wider audience.

**crDroid 12.12 is now available for supported devices.**
