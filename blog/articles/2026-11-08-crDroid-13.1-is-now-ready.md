# crDroid 13.1 is now released

We are happy to announce the release of crDroid 13.1, bringing the November 2026 security patches alongside a number of new features, customization options and improvements across the system.

This release focuses on refining the crDroid experience, with further improvements to the user interface, Dynamic Bar, system customization and Tricky Store, along with various fixes and updates throughout the platform.

## What's new

- Initial crDroid 13.1 release
- November 2026 Android security patches
- Added an option to enable or disable Dark theme automatically with Battery Saver
- More granular Monet customization options under crDroid > UI
- Improved Quick Settings header customization, accessible under crDroid > QS > Header image
- Added custom font selection in crDroid settings
- Added Pulse visualizer customization for height and custom color
- Added a Pixel-like weather pill widget for OmniJaws weather
- Improved Dynamic Bar, including message notifications, Bluetooth connectivity and memory leak fixes
- Improved SystemUI blur handling with a revamped blur engine, providing better performance for glass-like UI elements
- Updated Dynamic Bar to follow the system blur theme
- Improved OmniJaws weather refresh

## Tricky Store and spoofing

We have also made several improvements to Tricky Store and device spoofing:

- Added reminders for expiring keyboxes in Tricky Store
- Added automatic PIF refresh
- Improved support for custom keyboxes in Tricky Store
- Reworked PIF, Tricky Store and game properties spoofing
- Added the ability to configure spoofing options directly from crDroid settings
- Added new Pixel codenames to the PIF device list

More on PIF and Keybox with crDroid can be read [here](https://crdroid.net/blog/2026-11-07-keybox-and-pif-with-crDroid)

## Other improvements and fixes

Alongside the new features, this release includes a number of fixes and under-the-hood improvements:

- Fixed Bluetooth A2DP issues, including compatibility with codecs such as LHDC
- Fixed SetupWizard crashes with some GApps packages
- Fixed an IME spacing issue that could cause the language globe icon to appear twice
- Fixed incorrect taskbar creation after a clean flash
- Fixed contextual button behavior in Launcher3 when using phone gesture navigation
- Updated the Wi-Fi standard icon to use event-driven updates
- Added an option to disable the mobile data confirmation dialog in Quick Settings
- Improved scrolling between crDroid settings
- Improved ThemePicker icon previews when changing the accent color
- Centered clock style button labels in ThemePicker
- Modernized the recovery menu with Material 3 segmented cards
- Moved the launcher app-hiding feature to Sandbox
- Adjusted custom ROM detection behavior for certain apps
- Replaced Gallery2 with Canvas
- Updated Chromium WebView to 156.0.8078.47
- Updated translations

## Final words

With crDroid 13.1, we continue refining the experience with more customization options, improved system components and fixes across the board, while keeping the platform up to date with the latest security patches.

As always, we appreciate everyone who contributes to the project through testing, feedback and community support.

crDroid 13.1 is now available for supported devices.
