## crDroid 11.3 is now released!
----------------

We’re excited to introduce **crDroid 11.3**, bringing the latest **Android 15 QPR2 (android-15.0.0_r23) security patches for March 2025**, along with exciting new features, refinements, and fixes.

This release continues our mission of enhancing user experience while improving stability and performance.

### What’s new in crDroid 11.3 ###
**Security & Core Updates**
- Updated security patches to **March 2025 (android-15.0.0_r23)**.
- Improved translations across multiple languages.

**System Enhancements**
- **Modes replaces Do Not Disturb**  
  - **Complete overhaul of DND**, integrating it into the new **Modes system**.  
  - Create multiple **custom Modes** with schedules, notification filters, and more.  
  - Existing features like **Bedtime, Flip to Shhh, Game Dashboard, and Pixel Stand** are now part of Modes.  
  - Modes can be enabled from the **Quick Settings tile** and show an inline menu in the **status bar and lockscreen**.

- **Notification Cooldown**  
  - When receiving multiple notifications in a short time, **volume is lowered and alerts minimized** for up to 2 minutes.  
  - Calls, alarms, and priority conversations remain unaffected.  
  - Available under **Settings > Notifications**.

- **Wi-Fi Sharing UI Updates**  
  - The **QR code for sharing Wi-Fi credentials** now uses a **Material You shape**.

- **System UI Enhancements**  
  - **Toast messages now display the app’s icon** for better clarity.  
  - **Added prompts to restart SystemUI when required** for settings changes to apply properly.

**Customization & UI Updates**
- **crDroid Settings Changes**  
  - **Navigation tab and customization options removed**, with compatible settings **migrated to System settings**.  
  - **Sidebar customizations moved to Miscellaneous** for better organization.

- **Taskbar & Navigation**  
  - **Taskbar can now be enabled on recents gesture navigation**.

- **Lockscreen & Quick Settings**  
  - **Wind info & humidity on lockscreen are now disabled by default**.

**Bug Fixes & General Improvements**
- **Fixed various issues** in multiple areas of the OS for improved performance and reliability.
- **Polished animations and transitions** for a smoother experience.
- **Updated system components** to align with the latest AOSP changes.
