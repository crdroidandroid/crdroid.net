# crDroid 12.8 – March 2026 security patch

Late to post the news, considering we've got the source up beginning of the week, but lets go for it.  
crDroid **12.8** is now rolling out, bringing the March 2026 Android security patches along with a large batch of improvements, new customization options, and important bug fixes across the system.

This release focuses on polishing the user experience, enhancing SystemUI behavior, expanding lockscreen capabilities, and improving launcher performance — while continuing to refine stability for everyday use.

## What’s new

### Security & Core

- Merged March 2026 Android security patches
- Updated Chromium WebView to 145.0.7632.109
- Memory management improvements for screen-wake scenarios
- Improved compatibility with certain banking apps (reduced custom ROM detection)

### UI, Media & System Experience

- Added ongoing action chip implementation
- Squiggle seekbar for media progress panel
- Gradient styling for volume buttons and slider
- Added per-app volume support
- Fixed audio focus issues (disable multi-media focus if needed)
- Toggle for notification translucency
- Extended QS header image to support animated GIF/WEBP
- Data usage indicator option in QS footer
- Removed status bar brightness control (no longer compatible with latest Android source - may be revisited in future revisions)

### Lockscreen & Biometrics

- Added lockscreen widgets support
- Rewrote UDFPS icon picker and animations
- Fixed screen-off UDFPS
- Fixed fingerprint enrollment finish layout
- Status bar clock background chip styles

### Customization & Theming

- Gradient customization for QS tiles, brightness slider, and volume slider
- Monet settings illustration added
- System icon shapes moved to Launcher3
- Proper Material You (M3) theming for dialogs
- Multiple settings pages converted to modern preference dialogs

### Launcher & Recents

Launcher3 received a large set of improvements:

- Optimized All Apps performance and icon allocations
- Fixed recents issues when navigation hint is disabled
- Fixed row height customization in app drawer
- Added wallpaper pop-up carousel
- Added AI search icon for Gemini
- Fixed QSB layout issues and padding
- Set default search bar opacity to 80%
- Additional stability fixes and optimizations

### Quick Settings, Status Bar & Connectivity

- Added SoftAP client manager
- Option to disable private DNS while using VPN
- Fixed status bar clock reset issues
- Fixed AM/PM reset behavior
- Fixed roaming icon display
- Fixed incorrect positioning of custom status bar logo
- Fixed navbar inverse layout with taskbar enabled

### Stability & Bug Fixes

- Fixed secondary user crash when system user is locked
- Fixed privacy dashboard crash
- Fixed Google battery widget
- Fixed radio info menu (*#*#4636#*#*)
- Fixed recents freeze when navigation hint is disabled
- Fixed ambient display edge light, media art, and pulse issues
- Fixed various SystemUI glitches and layout problems
- Fixed navbar issues when hint is disabled
- Fixed incorrect display of custom status bar logo

### DeskClock Updates

- Migrated to Material 3 Expressive design
- Fixed screensaver settings crash in Turkish locale
- Fixed night mode color preference bug
- Resource optimizations and cleanup

### Other Improvements

- Keyboard app improvements
- Added battery optimization shortcut from power usage summary
- Added missing Adaptive Connectivity icon
- Updated settings illustrations from Canary
- Updated translations
- Numerous smaller fixes and refinements throughout the system

## Notes

This is a feature-rich update compared to the previous release, bringing both visible enhancements and deep system improvements. Dirty flashing from 12.7 should work fine in most cases, though a clean flash is recommended if you encounter unusual issues.

As always, device-specific changes may vary depending on the maintainer.

If you run into problems, please report them through the usual channels so they can be addressed in future builds.
