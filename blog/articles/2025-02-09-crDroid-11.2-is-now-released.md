## crDroid 11.2 is now released!
----------------

We’re excited to introduce **crDroid 11.2**, bringing the latest **Android 15 QPR1 (android-15.0.0_r14) security patches for February 2025**, alongside multiple enhancements and fixes.

This release builds upon our complete code rewrite, refining the user experience with new features, improved stability, and performance optimizations.

### What’s new in crDroid 11.2 ###
**Security & Core Updates**
- Updated security patches to **February 2025 (android-15.0.0_r14)**.
- Improved translations across multiple languages.

**System Enhancements**
- **Refined Heads-up Notifications**  
  - Fixed "Less boring heads-up" option.  
  - Added **compact heads-up toggle** for a more streamlined experience.  

- **Navigation & Gestures**  
  - Moved "Circle to search" toggle to **navigation gesture settings**, improving 3rd party launcher support.  
  - Navigation gesture settings are now located under **Settings > System**.  

- **Lockscreen & Quick Settings**  
  - Added optional **wind info & humidity** to the lockscreen.  
  - Added **Private DNS Quick Settings tile**.  
  - Implemented **split shade QS** for better usability.  
  - Removed **power menu shadow** for a cleaner look.  

- **Battery & Performance Fixes**  
  - Fixed **Google’s battery widget** not displaying correctly.  
  - **Disabled default frame rate limit for games** (introduced in Android 15).  
  - Addressed **memory leaks** in **WiFi** and **system extensions**.  

**User Interface Improvements**
- **SystemUI**  
  - Applied **burn-in translations** to the weather view.  
  - Prevented indicator text from **cutting off** in biometric prompts.  
  - Implemented **pocket lock check for Face Unlock**.  

- **Launcher3**  
  - **Updated folder preview and background color**.  
  - **Fixed race conditions** when toggling settings.  
  - **Improved taskbar corner radius**.  
  - **Fixed app search results visibility** for profiles in quiet mode.  
  - **Updated Lens intent in Quick Search Bar (QSB)**.  
  - **Set app drawer opacity to 100%** for a cleaner look.  
  - **Kept clear-all button from being disabled**.  
  - **Fixed taskbar crash** when disabled on foldables.  

- **Miscellaneous Fixes & Updates**  
  - **Restored system dynamic colors** for QS theme.  
  - **Fixed LMOFreeform crash** in some scenarios.  
  - **Fixed per-app volume support**.  
  - **Fixed icon shapes corner radius inconsistencies**.  
  - **Updated LatinIME keyboard** for better input handling.  
  - **Dialer:** Fixed **blinking hint text**.  
  - **Messaging:** Replaced outdated **AOSP illustrations**.  
  - **DeskClock:** Fixed **angles in dynamic icon**.  
  - **Telephony updates** for better reliability.  
  - **Updated themed icons** for a refreshed look.  
  - **Updated Twelve, Glimpse, and Catapult launchers**.
