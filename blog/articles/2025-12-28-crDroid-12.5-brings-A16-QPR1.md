# crDroid 12.5 Release 🎉

We’re happy to announce the official release of **crDroid 12.5**, based on **Android 16 QPR1**. This update focuses on platform freshness, security, and overall stability, with multiple fixes and improvements across the system.


## 🔥 Highlights

- Android 16 QPR1 features
- December security patches
- Various fixes and improvements


## ⚠️ Removed features

Unfortunately, due to **incompatibilities with the current AOSP code**, the following features have been removed in this release:

- Per-App volume  
- Custom volume steps  
- Battery styles  

These removals were necessary to ensure stability and proper integration with upstream changes.
